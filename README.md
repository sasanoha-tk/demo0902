# drift

慣性ドリフトと惑星着陸のローグライトアクション。宇宙を漂い、惑星に降り、生き延び、跳躍ゲートで次の星系へ進む。

## モジュール構成

- `core/` — ゲームロジック（プラットフォーム非依存・Kotlin + libGDX + Fleks ECS）
- `desktop/` — LWJGL3 ランチャー（**開発専用**：PCで高速反復）
- `android/` — 配布対象の Android アプリ（APK）

## 機能

- **慣性ベースの操船**: 摩擦ゼロの宇宙ドリフト。通常移動には速度上限があり、ダッシュのみ上限を超えて加速。着陸すると地表で摩擦が戻る。
- **惑星と地表探査**: 宇宙から惑星に着陸し、バイオーム（自然/火山/氷/ガス/死の惑星/孤独な小惑星）ごとに異なる地表を探索。往復ループ（着陸⇄発進）に対応。
- **惑星の記憶**: 一度降りた惑星の生態系は宇宙側で変動し、再訪すると地表の状態が変わる（惑星ごとに記憶として保存）。
- **戦闘とビルド**: 9種の武器（ピストル/ショットガン/マシンガン/ビーム/グレネード/SMG/ライフル/レールガン/帰還刃）、近接コンボ、壁設置、16種の強化カードでビルド構築。カードは1ランにつき1つの乱数列から配られ、セーブに記録される。
- **敵・ボス・波**: 165種の敵、6種のボス、15種の中ボス、賞金首、生態系への干渉で変わる波。
- **星系進行とメタ**: ジャンプゲートで星系を移動、星系ごとの目標、持ち帰り素材、惑星の記憶、死因レガシー、周回（1周ごとに波が2波深く、全増援が1レベル上。3周で上限の+6波/+3レベル。持ち越しの武器とアイテムは1周/2周で1個ずつ。クリア回数はアカウント共通）、3つのセーブスロット。
- **経済**: 惑星ごとの市場と需要係数、行商船、装備の持ち出し判定、消耗品と資料品の売買。
- **モード**: 通常ラン、旧式戦闘訓練（同じ宙域に実際の装備を持ち込んで練習。着陸・セーブ・獲得・クリア判定なし）。訓練場はメニュー項目としてのみ存在。
- **難易度**: 3段階（安定運転 / 標準 / 過負荷）。選択はセーブとメタ進行に記録される。
- **調整モード**: タイトル画面のパスコードで開く開発用ノブ（確率・重み・係数）。アプリの再起動で閉じる。
- **エンディング**: 同期90%で終局の扉が開き、1ランに3種の選択肢が並ぶ。確定の2種（眠り／漂流継続）に加えて、惑星の記憶が記録した干渉の履歴で「網を解く」か「刻まれた名を受け入れる」のどちらか1種。全4種を実装済みで、開く方は慈悲/敵対の割合と子どもへの危害が決める。
- **快適性・国際化**: 左利き配置、画面揺れ軽減、閃光軽減、エイム補助、音量設定、実行時生成の音效、英語表示など。

## 操作

| 操作 | キーボード（開発） | タッチ（Android） |
|------|----|----|
| 移動 | WASD / 矢印 | 左スティック |
| 射撃 | K（押しっぱなし、マニュアル系は離して発射） | FIRE |
| 近接 | J | ML |
| ダッシュ（向き方向・強加速・スタミナ大） | Shift | DASH ボタン |
| 流しダッシュ（スティック方向・微加速・スタミナ極小） | — | 左スティックを大きく倒す |
| リロード | R | RL |
| 壁設置 | F | WALL |
| 着陸 / 発進（惑星 ⇄ 宇宙） | L | 惑星またはスキャンカードをタップ／緑の着陸ボタン |
| 武器切替 | 1〜5（所持スロットに応じて） | WPN（順送り） |
| インベントリ（装備/アイテム/市/マップ/セーブ/ログ） | I | 持物ボタン |
| フルスロットル（OC スラスター装備時） | O（押しっぱなし） | 全開ボタン |
| 強化カード選択 | 1 / 2 / 3 | （数字キー） |
| リスタート | R（ゲームオーバー時） | — |

ゲームパッド（Xbox レイアウト）にも対応: 左スティック=移動、右スティック=照準+自動射撃、A=ダッシュ、R1=フルスロットル、X=近接、Y=リロード、B=着陸/発進。

> 宇宙は摩擦ゼロの慣性移動です。手を離しても減速せず、向きを変えるには逆方向への推進が必要になります。地表では摩擦が戻ります。

## 開発

```bash
# 前提: JDK 17 以上（JDK 21 で動作確認済み）, Android SDK (local.properties に sdk.dir)

# デスクトップで起動（開発用）
./gradlew :desktop:run

# ユニットテスト（core のみ）
./gradlew :core:test

# デバッグ APK をビルド
./gradlew :android:assembleDebug   # → android/build/outputs/apk/debug/

# core のみテスト（Android AGP が解決できない環境向けの簡易スクリプト）
./coretest.sh
```

| ディレクトリ | 役割 |

| `screens/` | `App` から切り替わる画面。`TitleScreen`、`GameScreen`（入力/HUD/演出/写真モードに分割） |
| `render/` | シーン描画、HUD、フォント、タッチオーバーレイ |
| `ui/` | タイトル・ポーズ・設定・インベントリ・行商・調整治具などのパネルとレイアウト |
| `input/` | キーボード・タッチ・ゲームパッド入力とハプティクス |
| `combat/` | 武器定義、射撃、近接、弾道、爆発、リロード |
| `config/` | `GameConfig`（player/weapons/ai/wild/waves/upgrades/enemies）と JSON コーデック、既定敵名簿、生態系カーブ、調整ツール |
| `map/` | タイルマップ、バイオーム、宇宙/地表ステージ生成、地形装飾 |
| `planet/` | 惑星バイオーム（6種） |
| `item/` | 装備・消耗品・資料品のカタログ、市場、行商、合成 |
| `save/` | Preferences 永続化（セーブスロット・惑星の記憶・死因レガシー・周回解放・エンディング・調整モードの解錠） |
| `audio/` | 実行時生成の効果音・環境音・BGM、音量/ダッキング |
| `i18n/` | 表示層の日英辞書（HUDとラベルの翻訳、名前台辞からの英語名生成） |

## 保存データ

ランは離陸・死・アプリポーズの各地点でチェックポイントし（v2.174 命綱）、インベントリのSAVEタブから任意でもセーブする。自動で「復刻」する設定はない。スロットごとに独立に残るのはランのセーブ、宇宙の記憶、死因レガシー。エンディングの記録（= クリア回数として周回に進む）と快適性設定はアカウント共通で、スロットを切り替えても引き継ぐ。『宇宙の記憶を消す』は惑星の記憶だけ消し、ランのセーブとエンディングの記録はそのまま（確認あり。一度失った記憶はリセットでも戻らない）。

## 現在地の見通し

`v2.192.0` 時点で、当面の機能追加は一段落。次の候補:

- 周回プレイのコンテンツ深度とバランス調整
- チェックポイントの範囲拡大と低レイテンシ化（現行は離陸・死・アプリポーズ地点）、PCセーブの外部化・エクスポート、複数スロット間の切替
- 高解像度・高リフレッシュレートと低スペック機の両面での最適化
- 地上・宇宙それぞれの環境音/戦闘音楽の強化

## テストの設計意図

`core/src/test/` に約1,000件。テストはプロシージャル生成・宇宙物理・重力well・地表力学・跳躍航法・波・目標・惑星の記憶・セーブ往復・エンディングと周回解放・調整ノブ・経済と市場の飽和・UIレイアウト・操作チュートリアルなどを中心にすえてある。狙いは、ゲームロジックを純粋なまま保つこと、世界生成が決定的で保存可能であること、操作説明が実際のHUDと入力と同じ表面を見ていること。
